# 📚 AI Study Buddy

Your smart AI-powered learning assistant that answers questions on **any subject**!

## ✨ Features
- 🤖 Powered by Meta Llama 3.1 via Hugging Face
- 📖 Answers any question — CS, Math, Physics, Biology, History & more
- 💬 Multi-turn conversation support
- 🚀 Fast and accurate responses

## 🛠️ Tech Stack
- **Frontend & Backend:** Gradio
- **AI Model:** meta-llama/Llama-3.1-8B-Instruct
- **Platform:** Hugging Face Spaces

## 🎯 How to Use
1. Type your question in the chat box
2. Press Enter or click Send
3. Get detailed, clear answers instantly!
